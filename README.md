# Cedos OS

O sistema usado pelo Cedos, o robô de Trekking da [Robota](https://www.instagram.com/robota.ufsc/), que estreou na [RSM Challenge de 2025](https://events.robocore.net/rsm-2025/).

## Equipamento

- ESP32
- Tira de colorida de LEDs individualmente endereçáveis
- O corpo da Tardis
- _Pack_ de baterias
